# 把项目讲成一个研究问题

这个项目适合用来准备 AI + 经济的研究讨论。下面给的是讲解框架与动手任务；具体结果以 `findings.md` 为准。

## 一分钟介绍的四句话

1. **问题**：职业培训后收入更高，可能来自项目，也可能来自本来就不同的参与者；我要区分这两件事。
2. **设计**：使用相同受训者，更换随机对照组与 CPS 观察性对照，比较未调整差异和交叉拟合 AIPW。
3. **验证**：同时检查重叠、平衡、分折与截断敏感性，并用培训前收入负对照与已知效应仿真检查方法边界。
4. **结论**：机器学习能改善条件模型，但识别来自假设和研究设计；点估计看起来合理仍可能无法作可信因果解释。

## 最容易被追问的八个问题

### 1. 为什么预测准确率高，不代表因果效应正确？

预测是根据观察到的关联恢复 Y；因果推断要估计同一个人在另一种处理状态下的反事实。数据中的处理选择机制可能依赖遗漏变量，预测器并不会因此获得未观察的反事实。

### 2. 这里是 ATE 还是 ATT？

ATT，只针对受训者。换成普通调查样本的总体 ATE 会改变目标人群，不能与原来培训人群的效果直接等同。恒定效应仿真中 ATE 和 ATT 恰好相等，真实数据并未假定效应恒定。

### 3. 双重稳健是什么意思？

在识别假设成立并满足相应正则条件时，结果模型或倾向得分模型一方足够正确可以支持一致性。它不是“两边都随便训练就可靠”，也不是对未观测混杂的稳健性。持续进行概率截断还会引入额外偏差问题。

### 4. 为什么必须交叉拟合？

同一观察如果同时参与拟合和计算 score，过拟合可能污染 score。分折让每行使用没有见过该行的模型预测。标准化也要仅在训练折拟合。它减少拟合偏差，但不修复样本选择或遗漏混杂。

### 5. 有一万多对照，为什么效果仍可能不稳定？

重要的是受训者相关协变量区域有多少可比对照。ATT 权重可能集中到少量对照；ESS 可能远小于原始人数。低倾向得分的巨大对照组不会自动提供受训者反事实的可靠信息。

### 6. 为什么不是“选最接近 1794 美元的模型”？

1794 是这份随机样本的估计值，带区间和抽样误差，不是已知真值。用它反复挑模型会形成基准泄漏。两套分析还共享受训者，不能当作独立估计比较显著性。

### 7. 负对照为什么有意义？

培训不能改变过去的收入。如果将处理前收入作为结果仍出现明显“效应”，需要检查选择机制、模型或负对照设计。此时必须从 X 中移除该收入，否则把结果送进模型会使检查失去意义。通过负对照也不能证明无混杂。

### 8. 你准备如何扩展？

先挑一个明确问题，例如：ATT 是否需要对接近零的 propensity 进行下端截断？预先规定比较单侧/双侧截断，在固定仿真机制与多次重复中比较 bias、RMSE、coverage、ESS，再讨论真实案例的变化。比继续添加很多模型更容易形成一条可论证的研究线。

## 将它变成你能掌握的作品

1. 在新虚拟环境复现全部结果，记录你的环境与耗时。
2. 手推 ATT score 及包含 `D*theta` 的影响函数，解释为何分母是受训者人数。
3. 阅读一篇原始数据研究和 Imbens-Xu 的重分析，各写一页自己的问题与理解。
4. 只选择一个扩展，先写实验方案，再跑实验；保留失败或反直觉结果。
5. 提交你自己能解释的修改、实验记录和局限分析，形成可追踪的研究过程。
