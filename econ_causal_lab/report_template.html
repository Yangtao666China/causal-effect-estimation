i How to read this experiment
先界定问题

ATT 关注“已接受干预的人，如果没有接受干预，结果会有什么不同”。

再检查可比性

倾向得分、协变量平衡与有效样本量帮助识别数据支持不足；预测表现不等于因果识别。

最后解释差异

灵活模型能学习非线性关系，估计差异也可能来自重叠不足、模型偏误或未观测混杂。

观察数据的因果解读依赖不可检验假设。截断权重不修复未观测混杂，也不保证找回真实效应。

Linear baselineML · Boosting

倾向得分截断到 [ε, 1−ε]。曲线变化提示估计对极端权重的依赖；阈值的选择不能由“更接近参考”来决定。

Known-truth simulation / 已知真值仿真

在可控数据生成机制下检验估计与不确定性

Bias 越接近 0 越好，RMSE 越小越好，95% 区间覆盖率应接近 95%。仿真覆盖率仅作诊断，不能证明真实观察数据上的因果有效性。

Pre-treatment placebo / 处理前收入负对照

用 1975 年收入作为结果变量，协变量中移除 re75 · 当前数据集

Training cannot change the past

培训不应改变过去。显著偏离 0 提示识别或模型问题；接近 0 不证明没有混杂。此处的区间仍为有限样本下可能失准的近似 95% 区间。
